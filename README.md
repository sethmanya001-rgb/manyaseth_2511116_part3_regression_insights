# manyaseth_2511116_part3_regression_insights
# Part 3: Regression Based Business Insights
## Retail Chain Sales Analysis

---

## Business Problem Summary

A retail chain wants to understand what factors are 
driving monthly sales performance across stores.

Leadership is considering:
- Increasing marketing spend
- Improving inventory availability
- Changing discounting strategy
- Reallocating staff
- Prioritizing certain store types or regions

Our task is to use regression analysis to identify 
which factors are most strongly associated with 
monthly sales and provide a business recommendation.

---

## Dataset Description

File: data/business_regression_data.xlsx

Total Records: 320 rows
Total Variables: 14 columns

The dataset contains monthly store level data including
sales performance, operational metrics, and store 
characteristics.

---

## Dependent Variable

monthly_sales — Total sales generated by a store 
in a given month. This is the variable we are trying 
to predict and explain.

---

## Independent Variables

Numerical Variables:
- marketing_spend: Amount spent on marketing per month
- footfall: Number of customers who visited the store
- avg_discount_pct: Average discount percentage offered
- staff_count: Number of staff in the store
- inventory_availability_pct: Percentage of inventory available
- competitor_distance_km: Distance to nearest competitor
- holiday_flag: Whether the month had a holiday (0 or 1)
- customer_rating: Average customer satisfaction rating

Categorical Variables:
- region: East, North, South, West
- store_type: Mall, Airport, High Street, Residential

Variables Not Used in Regression:
- store_id: Only an identifier, no analytical value
- month: Date variable, not used directly
- monthly_profit: This is also an outcome variable,
  not an independent variable

---

## Missing Values

- competitor_distance_km: 6 missing values
- customer_rating: 8 missing values
- All other columns: No missing values

---

## Regression Approach

Step 1: Simple regression models using one variable
at a time to understand individual relationships

Step 2: Multiple regression model using several 
variables together including dummy variables

Step 3: Compare models using R-squared and p-values

Step 4: Residual analysis to check model quality

---

## Dummy Variable Approach

Categorical variables cannot be used directly in 
regression. We convert them to dummy variables:

For region (4 categories: East, North, South, West):
- Created 3 dummy variables
- Reference category: East
- Dummies created: North, South, West

For store_type (4 categories):
- Created 3 dummy variables  
- Reference category: Residential
- Dummies created: Mall, Airport, High Street

---

## Model Comparison Summary

Three models were built and compared:
- Model 1: Simple regression with marketing_spend
- Model 2: Simple regression with footfall
- Model 3: Multiple regression with all key variables

See analysis/model_comparison.md for full details.

---

## Final Model Selected

Multiple regression model with:
- marketing_spend
- footfall
- avg_discount_pct
- inventory_availability_pct
- customer_rating
- Region dummy variables
- Store type dummy variables
